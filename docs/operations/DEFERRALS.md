# Deferrals register

- **What this is**: the single repo-visible place for deferred decisions
  and their reopen conditions; every row cites the decision doc that
  deferred it.
- **Reconcile**: the session-start `reconcile` pass reads this file — a
  stale register is worse than none, so it prunes rows that no longer hold.
- **Resolved rows** move to [Resolved](#resolved) with the landing commit;
  they are never deleted silently.
- **Same-commit rule**: any new "deferred" line in an audit plan, a plan
  file, or a `plans/README.md` row must add its entry here in the same
  commit.
- **Deferred (of itself)**: the mechanical stale-date check
  (`tools/check-deferrals.mjs` wired into `validate`) — build it only if
  the manual pass proves forgettable.
