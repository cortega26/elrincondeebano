# Plan 055 Compatibility Fixtures

Synthetic test data for validating TypeScript Content Manager parity against the Python Tkinter manager.

These fixtures exercise every optional field, edge case, and Unicode scenario the migration must preserve. No fixture uses production catalog data, real assets, or real credentials.

## Catalog structure

| File                         | Coverage                                                                                                                                  |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `product_catalog.json`       | 9 products: basic, full, archived, out-of-stock, free-discount, Unicode emojis/bullets, empty description, categories with/without spaces |
| `category_registry.json`     | 3 nav groups, 4 categories covering all optional fields (display_name, description, nav_group, active, sort_order)                        |
| `storefront_experience.json` | trust bar, home categories, fallback picks, featured staples, 2 bundles with prices, companion rules                                      |

## Edge cases covered

- [x] Product with minimum required fields only
- [x] Product with all optional fields (images, discount, field_last_modified on every key)
- [x] Archived product (`is_archived: true`)
- [x] Out-of-stock product (`stock: false`)
- [x] Free product (discount == price)
- [x] Unicode in name/description (emoji, bullet point, regional characters)
- [x] Empty description
- [x] Empty image paths
- [x] Category with spaces in key (Limpieza y Aseo)
- [x] Category without spaces (Despensa, Lácteos)
- [x] Category registry with nav_groups nested structure
- [x] Bundle with bundlePrice
- [x] Companion rules
- [x] Multiple field_last_modified entries per product
- [x] Catalog-level rev ≠ 0
- [x] Product revisions (rev 1, 2, 3)

## Regression gates

| What is lost?                   | Detection                                        |
| ------------------------------- | ------------------------------------------------ |
| Optional field dropped          | Zod `.optional()` preserves undefined vs missing |
| Revision lost                   | contract test compares `rev` round-trip          |
| field_last_modified lost        | contract test checks all metadata keys           |
| Category key casing changed     | exact match assertion                            |
| Unicode mangled                 | byte-equivalent normalization test               |
| Archive state misinterpreted    | boolean identity check                           |
| Discount > price ignored        | validation error, not silent clamp               |
| Empty string treated as missing | `""` ≠ field absence                             |
